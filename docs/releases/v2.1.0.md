# Control Plane v2.1.0

Status: published as the immutable `v2.1.0` tag and GitHub Release from
`955099531ae7cbb8a88208456b811527977105fd`.

## Included

- proportional local-audit routing and fail-closed Git guards;
- explicit Continuation Pointer at every logical close;
- BUSTAFIT dogfood corrections for requested outcomes, hybrid profiles and
  compact context budgets;
- host-native, read-only cross-thread continuation lookup;
- supported, isolated and exactly reversible adoption and upgrade for Generic,
  iOS and hybrid projects;
- deterministic release candidate bound to remote `main`, CI gates and
  SHA-256 evidence.

## Supported adoption

Verify `SHA256SUMS`, extract the source tarball, keep its
`.codex/release-source.json` intact, and follow
`docs/engineering/07-adoption.md`: plan, inspect JSON, apply, verify,
project gates, manual `/hooks` review, one exact rollback trial, then a fresh
plan and application. The installed runtime is isolated from the source
checkout and rollback restores the previous project state. Plan and apply both
recheck bounded file hashes plus the reconstructed Git tree and commit object.

## Deferred

Soft enforcement, consumer-project CI, Rulesets, deploy, TestFlight, global
plugins and Ponytail remain outside this release. Missing provider evidence is
`UNKNOWN`, never `PASS`.
